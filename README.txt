CLUB LOVE — SITE

1. Abra script.js e troque WHATSAPP_NUMBER pelo seu número com código do país, sem +, espaços ou símbolos.
   Exemplo Brasil: 5521999999999
2. Abra index.html no navegador para testar.
3. O formulário envia os dados preenchidos para o seu WhatsApp em uma mensagem pronta.
4. Este pacote é um site estático: os dados não são salvos em banco de dados. Para cadastro persistente, será necessário um backend/banco de dados.
